Command skill: altaika agent

Use when an agent needs machine-readable CLI affordances.

Best path:
1. Start with `altaika agent schema`.
2. Prefer commands listed there over guessing flags.
3. Use command help when a command needs human-readable guidance.
4. Use `altaika agent issue-template` when behavior should become a GitHub issue.

If schema and help disagree, file an issue with both outputs.
